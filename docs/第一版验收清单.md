# 第一版验收清单

未勾选即未验收。测试通过与真机验证分开记录。

## 工程与规则

- [x] 原商城无写入，新项目独立 Git，无商城远端/签名/凭据。
- [ ] 新包名可安装，与商城共存；App 名称正确。
- [x] 本地构建、测试、Lint、格式、架构检查通过，CI 配置使用同一入口。
- [x] GitHub 首次 CI 六项通过；main 已配置 PR、分支同步、讨论解决及六项必需检查，并禁止管理员绕过、强推和删除。
- [x] 主题选择提供墨青绿、石板蓝、暖琥珀、莓果玫瑰四种配色，以及跟随系统、浅色、深色三种显示模式；默认“石板蓝 + 跟随系统”。
- [ ] 主题偏好本机持久化、退出不清除、进程重启可恢复；未知或读取失败值安全回退默认，写入失败不误报成功（实现和异常单测已完成，待设备进程重启验证）。
- [x] 四种配色的浅深 Token 完整，无 Material 默认紫色泄漏。
- [ ] “每日一问”使用中性表面和克制的主色标记，不使用突兀的大面积异色背景（问答功能尚未实现）。
- [ ] 主题切换、三个底部入口、系统栏图标、大字体、Insets、触摸目标和无障碍语义完成设备验证。

## 首页与搜索

- [ ] 问答取最新最多 5 条，一次 1 条、纵向循环；不足 5 条正常，单条静止。
- [ ] 后台/页面不可见停止轮播；不重复请求，点击对应当前条目。
- [ ] 问答与文章独立失败；文章刷新、加载更多、失败重试、末页正确（文章部分本地实现和单元测试完成，待设备验收）。
- [ ] 使用普通文章流时标“最新博文”，不假称热度排序。
- [ ] 搜索输入、提交、分页、无结果、失败重试和旧请求失效。

## 专题

- [ ] 一级二级平铺保留原 ID/parentId，默认第一项，同名不同 ID 不误合并。
- [ ] 父级查询能力实测通过，或替代方案得到用户明确确认。
- [ ] 分类状态/页码/滚动位置隔离；快速切换不串列表。
- [ ] 阅读返回及 Tab 切换保留分类和位置。

## 阅读与本地

- [ ] HTTPS 阅读、加载进度、失败重试、网页历史优先返回。
- [ ] 外部 App 跳转确认，不绕过 TLS，不给第三方注入 API Cookie。
- [ ] WebView 正确释放，进程/Activity 重建可恢复必要路由。
- [ ] 深色模式下原生阅读界面正确；第三方 WebView 按页面能力或受控算法变暗处理，不宣称所有网页都能完整暗色化。
- [ ] 历史与缓存分表；历史记录不假称缓存成功。
- [ ] 自动缓存不阻塞阅读；成功缓存正文断网可打开，不支持的页面明确提示。
- [ ] 限制单篇/总容量/并发/超时；净化 HTML；中断不永久缓存中。
- [ ] 重复历史去重；独立单条/全部清理；分页读取列表，正文按需读取。
- [ ] Migration 及数据库事务测试；无 destructive fallback；备份排除本地数据。

## 登录与收藏

- [ ] 用户名密码登录、错误提示、退出、会话恢复、失效统一处理。
- [ ] 未登录可访问公开页面和本机数据；收藏引导登录后返回，不自动重放写操作。
- [ ] Cookie 域/路径/有效期匹配，日志脱敏，不存明文密码。
- [ ] 收藏/取消去重，文章 ID 与收藏记录 ID 区分，页面同步。
- [ ] 超时结果不确定时重新校准，不盲目重试。
- [ ] 退出/账号切换让旧请求失效，收藏数据隔离；本机历史及缓存保留。

## 发布与不包含项

- [ ] 离线首次启动、慢网、无网、旋转、进程恢复、返回栈专项验证。
- [ ] Release 构建及混淆检查，敏感日志/调试工具检查。
- [ ] 真机设备和测试日期、失败和未验证项明确记录。

暂不包含注册、找回密码、资料编辑、推送、后台批量下载、云端历史同步。

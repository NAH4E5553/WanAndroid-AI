## 公开接口探测

参考：[玩 Android API 文档](https://wanandroid.com/blog/show/2)。只读取公开接口，无登录、收藏或其他服务端写操作。

- tree/json：errorCode=0，返回 61 个一级节点。
- cid=150（开发环境）：total=169；cid=60（其子类）：total=40。
- cid=167（基础知识）：total=111；cid=168（其子类）：total=21。
- 上述均请求 article/list/0/json?page_size=2，响应 curPage=1、over=false。
- 结论：抽样父类 ID 可直接请求，不需要先引入跨子类分页聚合；不是保证全部分类有内容。
- wenda/list/1/json：errorCode=0，20 条；应用取前 5 条。是否需要剔除置顶等特殊排序，在功能接入时确认响应语义，不自行按 ID 排序。
- 第一版列表标题采用“最新博文”，不声称公开首页列表按热度排序。
